# Publication System

## Description

This Python project demonstrates object-oriented programming with a `Publication` base class and `Book` and `Magazine` subclasses. It models shared publication details while adding page or issue information specific to each publication type.

## Why It Exists

The project provides a simple example of inheritance, encapsulation, validation, setters, getters, and polymorphic `display_info()` methods.

## How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in the repository folder.
3. Run:

   ```bash
   python Project1/pythonfile1.py
   ```
